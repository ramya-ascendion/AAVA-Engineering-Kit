# Work is cut into vertical slices, each named for what a person can do when it is finished

A slice is a thin path through every layer that ends with something a person can do. It is not a layer, a component or a technical phase.

## Why

A layer finishes with nothing to demonstrate and nothing to learn from.

## Consequences

- A spec opens with the one-sentence "what a person can do" line.
- See `docs/agents/slices.md` and `docs/agents/delivery-frontier.md`.
